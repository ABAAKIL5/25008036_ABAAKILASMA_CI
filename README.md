# CI12 — Prévision des exportations agroalimentaires marocaines

## 1. Présentation du projet
Ce projet porte sur la prévision des exportations agroalimentaires du Maroc, notamment les tomates, les agrumes et d'autres produits agricoles.

## 2. Objectif
L'objectif est d'utiliser des techniques de Machine Learning pour analyser les données historiques et prévoir la valeur des exportations agroalimentaires marocaines.

## 3. Source des données
- UN Comtrade
- FAOSTAT

## 4. Algorithme
Ridge Regression.

## 5. Structure du dépôt
- `data/` : données du projet.
- `docs/` : fiche du sujet et références.
- `notebooks/` : notebook Python.
- `figures/` : graphiques et visualisations.
- `rapport/` : rapport final.
- `presentation/` : présentation du projet.
- `video/` : vidéo de démonstration.

## 6. Outils utilisés
- Python
- Google Colab
- Pandas
- Matplotlib
- Scikit-learn
